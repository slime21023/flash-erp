# FlashERP 核心術語表（Glossary）

本表協助產品使用者、開發者與營運人員對核心業務概念使用相同名稱。它是概念約定，不是目前程式碼、資料欄位或 API 名稱的清單；定義清楚優先於逐字對應實作。

## 使用原則

- 首次提到術語時使用「中文名稱（English term）」；後續沿用中文名稱。
- 只收錄穩定、跨角色共用且可以獨立解釋的概念。
- 不收錄內部識別字、實作細節、過度相近或尚未有明確共識的詞；遇到這些情況時，先在相關設計文件釐清，不勉強塞入本表。
- 若現有程式名稱與本表用語不同，在相應技術文件說明對應關係；不要為了配合程式名稱而改變業務定義。

## 組織與交易對象

| 中文術語 | English term | 簡明定義 |
| --- | --- | --- |
| 公司 | Company | 獨立承擔業務及財務責任的企業主體。 |
| 客戶 | Customer | 購買或接受公司商品、服務的一方。 |
| 供應商 | Supplier | 向公司提供商品或服務的一方。 |
| 品項 | Item | 公司採購、庫存、製造或銷售的可識別商品或材料。 |
| 倉庫 | Warehouse | 用來存放及管理實體庫存的地點。 |

## 業務與製造

| 中文術語 | English term | 簡明定義 |
| --- | --- | --- |
| 核准 | Approval | 負責人確認一項業務決定可以繼續執行。 |
| 採購單 | Purchase order | 記錄公司向供應商採購商品或服務的約定。 |
| 銷售訂單 | Sales order | 記錄公司接受客戶商品或服務需求的約定。 |
| 出貨 | Shipment | 將商品從公司交付給客戶以履行銷售約定。 |
| 庫存 | Inventory | 公司持有並管理的實體商品與材料。 |
| 物料清單 | Bill of materials（BOM） | 製造一項產品所需的材料及用量清單。 |
| 製造工單 | Production order | 授權並記錄製造指定產品與數量的工作。 |

## 財務與計量

| 中文術語 | English term | 簡明定義 |
| --- | --- | --- |
| 會計分錄 | Journal entry | 以借方與貸方記錄一項經濟活動；借貸金額必須平衡。 |
| 數量 | Quantity | 以明確單位表示的商品或材料數量。 |
| 計量單位 | Unit of measure | 表示數量所使用的標準單位，例如個、公斤或公尺。 |
| 金額 | Monetary amount | 以指定幣別表示的價值。 |
